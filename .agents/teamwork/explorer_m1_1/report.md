## 1. Executive Summary

This investigation designs the exact, production-ready implementation strategy for **Milestone 1 — Solution Foundation & .slnx Configuration** for the `AutoMasters` application.

### Key Findings & Technical Decisions:
1. **Visual Studio 2026 `.slnx` Format:**
   The host system is equipped with **.NET SDK 10.0.401** and **Visual Studio 2026 Community (v18.x)**. The new XML-based Solution format (`.slnx`) is fully supported natively by both the CLI (`dotnet build`, `dotnet solution`) and Visual Studio 2026. The solution file `AutoMasters.slnx` placed at the workspace root points directly to `AutoMasters/AutoMasters.csproj`.
2. **Unpackaged Desktop Execution:**
   Targeting `net10.0-windows10.0.19041.0` with `<WindowsPackageType>None</WindowsPackageType>` and `<OutputType>Exe</OutputType>` allows the .NET MAUI desktop app to launch without MSIX packaging, certificate signing, or app installation hurdles, satisfying BTS SIO academic standards and immediate local execution.
3. **NuGet Packages & Offline Readiness:**
   All required packages (`Microsoft.Maui.Controls 10.0.20`, `CommunityToolkit.Mvvm 8.4.2`, `Newtonsoft.Json 13.0.4`, `Microsoft.Extensions.Logging.Debug 10.0.0`) are verified present in the local cache (`C:\Users\stent\.nuget\packages\`). Restores are 100% offline, deterministic, and fast.
4. **Zero-Warning Clean Build:**
   By configuring `<NoWarn>$(NoWarn);MVVMTK0045</NoWarn>`, WinRT AOT compatibility warnings generated by `CommunityToolkit.Mvvm` source generators on Windows desktop are suppressed, delivering an absolute zero-warning, zero-error compilation (`dotnet build AutoMasters.slnx -c Debug`).

## 3. Project File Configuration: `AutoMasters/AutoMasters.csproj`

### 3.1 Complete Verified File Content
File path: `c:\Users\stent\source\repos\AutoMasters\AutoMasters\AutoMasters.csproj`

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <!-- Cible du TP BTS SIO : execution Windows Unpackaged -->
    <TargetFramework>net10.0-windows10.0.19041.0</TargetFramework>
    <OutputType>Exe</OutputType>
    <RootNamespace>AutoMasters</RootNamespace>
    <UseMaui>true</UseMaui>
    <SingleProject>true</SingleProject>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
    <MauiXamlInflator>SourceGen</MauiXamlInflator>
    <ApplicationTitle>AutoMasters</ApplicationTitle>
    <ApplicationId>fr.fldsio.automasters</ApplicationId>
    <ApplicationDisplayVersion>1.0</ApplicationDisplayVersion>
    <ApplicationVersion>1</ApplicationVersion>
    <WindowsPackageType>None</WindowsPackageType>
    <SupportedOSPlatformVersion>10.0.17763.0</SupportedOSPlatformVersion>
    <TargetPlatformMinVersion>10.0.17763.0</TargetPlatformMinVersion>
    <!-- Suppression de l'avertissement MVVMTK0045 lie a WinRT AOT pour un build 100% propre -->
    <NoWarn>$(NoWarn);MVVMTK0045</NoWarn>
  </PropertyGroup>

  <ItemGroup>
    <MauiIcon Include="Resources\AppIcon\appicon.svg" ForegroundFile="Resources\AppIcon\appiconfg.svg" Color="#10080B" />
    <MauiSplashScreen Include="Resources\Splash\splash.svg" Color="#10080B" BaseSize="128,128" />
    <MauiImage Include="Resources\Images\*" />
    <MauiFont Include="Resources\Fonts\*" />
    <MauiAsset Include="Resources\Raw\**" LogicalName="%(RecursiveDir)%(Filename)%(Extension)" />
  </ItemGroup>

  <ItemGroup>
    <PackageReference Include="Microsoft.Maui.Controls" Version="10.0.20" />
    <PackageReference Include="CommunityToolkit.Mvvm" Version="8.4.2" />
    <PackageReference Include="Newtonsoft.Json" Version="13.0.4" />
    <PackageReference Include="Microsoft.Extensions.Logging.Debug" Version="10.0.0" />
  </ItemGroup>
</Project>
```

### 3.2 Detailed Property Rationale & Analysis

| Property | Value | Purpose & Architectural Rationale |
|---|---|---|
| `TargetFramework` | `net10.0-windows10.0.19041.0` | Targets .NET 10 with Windows 10 SDK 10.0.19041.0 (Windows 10 2004+), supported by the installed `maui-windows 10.0.20` workload. |
| `OutputType` | `Exe` | Generates a standard Windows `.exe` application binary. |
| `RootNamespace` | `AutoMasters` | Enforces the application root namespace matching `PROJECT.md`. |
| `UseMaui` | `true` | Activates .NET MAUI build targets, handlers, XAML compilation, and resource processing. |
| `SingleProject` | `true` | Standard MAUI single-project architecture consolidating platforms and resources. |
| `ImplicitUsings` | `enable` | Automatically imports common namespaces (`System`, `System.Collections.Generic`, `System.Net.Http`, etc.). |
| `Nullable` | `enable` | Enables C# nullable reference types and compile-time null safety checks. |
| `MauiXamlInflator` | `SourceGen` | Uses Roslyn source generation for XAML inflation instead of reflection for maximum startup performance. |
| `ApplicationTitle` | `AutoMasters` | Sets the application display title in the Windows title bar and taskbar. |
| `ApplicationId` | `fr.fldsio.automasters` | Academic package identifier under the BTS SIO academic domain `fr.fldsio.*`. |
| `WindowsPackageType` | `None` | **CRITICAL:** Configures **Unpackaged execution**. The app runs directly as a desktop Win32/WinUI 3 executable without requiring MSIX packaging, developer signing certificates, or app installation. |
| `SupportedOSPlatformVersion` | `10.0.17763.0` | Minimum supported OS version (Windows 10 version 1809). |
| `TargetPlatformMinVersion` | `10.0.17763.0` | Minimum platform version for WinRT projection tooling. |
| `NoWarn` | `$(NoWarn);MVVMTK0045` | Suppresses `MVVMTK0045` (WinRT AOT compatibility warning from CommunityToolkit.Mvvm on `[ObservableProperty]`). |

### 6.3 Diagnostic & Troubleshooting Matrix

| Potential Failure | Root Cause | Exact Remedy |
|---|---|---|
| `MSB1009: Project file does not exist` | Path in `AutoMasters.slnx` does not match directory on disk | Ensure `<Project Path="AutoMasters/AutoMasters.csproj" />` matches relative folder structure. |
| `APT2260` or Asset Resizer Error | Missing SVG/TTF files declared in `AutoMasters.csproj` `<ItemGroup>` | Ensure `Resources/AppIcon/appicon.svg`, `appiconfg.svg`, `Splash/splash.svg`, and fonts are present in `Resources/`. |
| `CS0246: The type or namespace name 'ConnexionPage' could not be found` | `App.xaml.cs` instantiates `ConnexionPage` before `Vues/ConnexionPage.xaml` is created | Ensure `Vues/ConnexionPage.xaml` is in place or bootstrap with a temporary empty `ContentPage`. |
| 12 warnings `MVVMTK0045` | WinRT AOT compatibility warning from CommunityToolkit.Mvvm | Suppress via `<NoWarn>$(NoWarn);MVVMTK0045</NoWarn>` in `AutoMasters.csproj`. |
| `NETSDK1005: TargetFramework mismatch` | Test project targeting `net10.0` references `AutoMasters.csproj` | Test project MUST target `net10.0-windows10.0.19041.0` (as verified in `AutoMasters.E2ETests.csproj`). |
